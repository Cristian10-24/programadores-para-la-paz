El comando `uname -a` muestra información general del sistema operativo, como el nombre del sistema, la versión del kernel y la arquitectura del equipo. El comando `whoami` muestra el nombre del usuario que está utilizando la sesión actual. Conocer esta información es útil al administrar un servidor porque permite verificar el sistema operativo, identificar el usuario con el que se está trabajando y facilitar tareas de configuración, mantenimiento y solución de problemas.
