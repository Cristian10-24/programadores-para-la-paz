# Programadores para la Paz

Repositorio creado para almacenar y organizar todas las actividades desarrolladas durante el programa **Programadores para la Paz**, realizado por Cristian Bedoya.

## Contenido

En este repositorio se podrán encontrar:

- Actividades semanales
- Ejercicios prácticos
- Proyectos desarrollados durante el proceso
- Evidencias y recursos de aprendizaje

## Organización

Las actividades estarán organizadas por semanas para facilitar el seguimiento del proceso formativo.
